درگاه پرداخت کارت‌به‌کارت واریزا برای ووکامرس، با تأیید کاملاً خودکار سفارش — بدون بررسی دستی رسید.

== Description ==

**واریزا** یک درگاه پرداخت کارت‌به‌کارت است که سفارش‌های ووکامرس را به‌صورت کاملاً خودکار تأیید می‌کند.

مشتری در تسویه‌حساب «واریزا» را انتخاب می‌کند، مبلغ را کارت‌به‌کارت واریز می‌کند و در عرض چند ثانیه، بدون هیچ بررسی دستی رسید توسط فروشنده، سفارش به‌صورت خودکار «پرداخت‌شده» می‌شود.

= امکانات =

* تأیید کاملاً خودکار پرداخت با وب‌هوک امضاشده (HMAC-SHA256)
* سازگار با چک‌اوت کلاسیک و چک‌اوت بلوکی ووکامرس (Cart & Checkout Blocks)
* بازخوانی خودکار وضعیت سفارش در صفحه‌ی نتیجه، بدون نیاز به رفرش دستی
* پشتیبانی از هر دو واحد پول تومان و ریال
* صفحه‌ی تنظیمات اختصاصی با راهنمای گام‌به‌گام راه‌اندازی

برای استفاده از این افزونه به یک حساب کاربری در [واریزا](https://variza.ir) نیاز دارید.

== Installation ==

1. افزونه را از پیشخوان وردپرس در مسیر افزونه‌ها ← افزودن ← بارگذاری افزونه نصب و فعال کنید.
2. یک حساب در [variza.ir](https://variza.ir) بسازید و کلید API و کلید امضای وب‌هوک را از پنل واریزا کپی کنید.
3. از منوی «واریزا» در پیشخوان وردپرس، کلیدها را وارد و ذخیره کنید.
4. آدرس وب‌هوک نمایش‌داده‌شده در همان صفحه را در پنل واریزا (پروفایل ← وب‌هوک) ثبت کنید.
5. درگاه را فعال کنید.
